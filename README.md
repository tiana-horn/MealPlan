# Meal Plan Tracker

A single-page tracker for the Cut and Bulk meal plans in `cut_bulk_nutrition.csv`.

- Separate Cut and Bulk sections with live daily totals (calories, macros, sugar, fiber, sodium, cholesterol)
- Remove foods with ✕; add foods from the food bank at the bottom to any meal
- Reset each plan to its original foods (Bulk can reset to any of the three dinner options)
- Changes are saved in your browser

Live site (GitHub Pages): https://tiana-horn.github.io/MealPlan/

Open `index.html` directly in a browser to use it locally. The CSV data is embedded in the page, so if you edit the CSV, paste the new contents into the `csv-data` script block in `index.html`.
